## Сцена и масштаб

Всё лежит в `#stage` 1920×1080 с `position: absolute` у каждого блока. Скрипт `fit()` масштабирует сцену под окно (`transform: translate(-50%,-50%) scale(k)`). Никаких медиазапросов и резиновой вёрстки — слайд должен выглядеть одинаково на ноутбуке и на видеостене.

Подписи с переносами ставь через `<br>` и `white-space: nowrap`: автоматический перенос на проекторе с другим сглаживанием шрифта может сломать строку.

## Карта под углом 45°

Рабочий пример целиком — `assets/examples/rezultaty.html`. Суть:

```css
.scene { position: absolute; inset: 0; perspective: 1700px; perspective-origin: 1210px 520px; }
.plane { position: absolute; left: 510px; top: -90px; width: 1400px; height: 1400px;
         transform: rotateX(var(--tilt)) scale(var(--zoom)); transform-style: preserve-3d; }
.ground { position: absolute; inset: 0;  /* карта, сетка, радар — всё плоское */
          mask-image: radial-gradient(circle at 50% 50%, #000 34%, rgba(0,0,0,.55) 46%, transparent 62%); }
```

- Карта вставляется меткой `<!--MAP-->` как встроенный SVG с классом `.geo`. Сборщик убирает её собственный тёмный фон — иначе под городом виден тёмный прямоугольник. `mix-blend-mode` для этого не годится: внутри 3D-плоскости он не работает.
- Края карты затемняй маской на `.ground`, а не на `.plane`: маска на элементе с `preserve-3d` сплющивает всё, что стоит над картой.
- Линии, лежащие на карте (маршрут, кольца, пульс), рисуй в SVG внутри `.plane`, в координатах плоскости 1400×1400, центр 700,700.
- Яркость карты: `opacity: 0.6; filter: brightness(1.5) saturate(0.85)` — карта фон, а не содержание.

## Маяки над картой

Блок, который стоит на карте и смотрит на зрителя: якорь в точке плоскости, развёрнутый обратно на угол наклона.

```css
.post { position: absolute; width: 2px; height: 2px; margin: -1px 0 0 -1px;
        transform: rotateX(calc(-1 * var(--tilt))); transform-origin: 1px 1px; transform-style: preserve-3d; }
.post .stem { position: absolute; left: -2px; bottom: 0; width: 4px; height: 112px; /* световой столб */ }
.post .sec  { position: absolute; left: 0; bottom: 104px; /* значок + номер + подпись */ }
```

Якорь обязан иметь ненулевой размер. С `width: 0; height: 0` Chromium считает слой пустым и не рисует детей вообще — координаты в DevTools правильные, а на экране ничего нет.

Подписи ставь с внешней стороны от центра (левым узлам — слева, правым — справа), иначе они лягут на карту и маршрут. Ближние к зрителю узлы из-за перспективы крупнее дальних — проверяй, что правые подписи не вылезают за 1920, а левые не наезжают на заголовок.

## Вступление по порядку

Наклон и приближение анимируются через зарегистрированные свойства — так маяки разворачиваются синхронно с плоскостью:

```css
@property --tilt { syntax: '<angle>'; inherits: true; initial-value: 45deg; }
@property --zoom { syntax: '<number>'; inherits: true; initial-value: 1; }
.scene { animation: fly 2.6s cubic-bezier(.2,.7,.2,1) both; }
@keyframes fly { from { --tilt: 0deg; --zoom: .62; opacity: 0; } 35% { opacity: 1; } to { --tilt: 45deg; --zoom: 1; } }
```

Очередь появления задаётся одной переменной `--i` на элементе: `animation-delay: calc(1.6s + var(--i) * .28s)`. Прорисовка линии — `pathLength="1"`, `stroke-dasharray: 1; stroke-dashoffset: 1` и анимация смещения к нулю.

Всё вступление — 3–4 секунды. Дольше докладчик ждать не станет. Обязательно добавь блок `prefers-reduced-motion` (есть в заготовке).

Атрибут `fill` на SVG-элементе проигрывает правилу CSS вроде `.net path { fill: none }` — заливку стрелок задавай тоже в CSS.

## Линии и потоки

- Линия = базовый штрих + размытая копия для свечения + поверх «бегущие точки» (`stroke-dasharray: 2 46` и анимация `stroke-dashoffset`).
- Градиент вдоль линии между двумя узлами: `linearGradient` с `gradientUnits="userSpaceOnUse"` и координатами концов.
- Направление показывай стрелкой в середине сегмента, повёрнутой по касательной.
- Трубы в изометрии: тёмный широкий штрих-«кожух», цветной штрих, тонкий светлый блик.

## Наведение

Связанным элементам давай общий `data-s="N"`; один обработчик ставит класс `.on` всем с тем же номером (блок, вкладка в шапке, его цифра). При уходе курсора — снимай. Наведение — украшение: слайд должен быть полностью понятен и без него, потому что на экране в зале курсора нет.

## Изометрическая сцена скриптом

Когда в сцене десятки повторяющихся деталей (этажи, окна, стояки), геометрию считает Python и вставляет SVG между метками `<!-- SCENE:BEGIN -->…<!-- SCENE:END -->` в исходнике. Смотри `assets/examples/house.py`: вверху константы проекции и размеров, ниже функции `tube()` и `flange()`. Меняешь размер дома — меняешь число, а не сотню координат. Запускай `python3 -I`.

Жизненная правда важнее красоты: заказчик поправил, что трубы входят в дом под землёй, в подвал. Перед тем как рисовать инженерный объект, проверь, как он устроен на самом деле.

## Колода из нескольких слайдов

Несколько слайдов в одном файле — это `<section class="slide">` на каждый, показ по `location.hash`, стрелки клавиатуры (не перехватывай их, когда фокус в поле ввода), навигация внизу. Для подключаемых `styles.css`/`app.js` добавляй `?v=<хэш>` — иначе браузер заказчика покажет старую версию из кэша.

## Публикация демо

Если нужен адрес для показа — GitHub Pages из ветки `gh-pages`. Историю не переписывай (force-push обычно запрещён): публикуй коммитом с тем же деревом поверх текущей ветки.

```bash
git fetch origin gh-pages
```

```bash
git push origin $(git commit-tree HEAD^{tree} -p FETCH_HEAD -m "Publish main"):refs/heads/gh-pages
```

Опубликованный адрес из облачной сессии может быть недоступен — честно скажи, что проверил локально, а ссылку заказчик проверит сам.

## Ошибки, которые уже были

| Что случилось | Как не повторить |
|---|---|
| Забыли пересобрать автономный файл после правки | Сборка и снимок — часть каждой правки, не отдельный шаг |
| Картинка слилась с фоном, «всё сливается» | Смотри снимок сам до того, как показывать |
| «Очень ярко» | Фон и карта приглушённые, яркий только смысловой акцент |
| Слайд «непропорционален» | Блоки выравнивай по общей сетке полей 82–96px, не оставляй пустых углов |
| Раскрасили по темам, а ждали по статусу | Спроси, что означает цвет, до раскраски |
| Нарисовали связи между разделами на оглавлении | Связи только там, где они есть по смыслу |
| Переплетение труб под картой получилось перегруженным | Новый слой проверяй на снимке; если спорит с существующими — предложи вариант спокойнее или откажись |
| Чужая страница была только скриншотом | Перерисуй по скриншоту и перечисли отличия от оригинала |
