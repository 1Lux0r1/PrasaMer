# Схема электроснабжения — цифровой двойник Москвы

Рабочий макет презентации: четыре слайда (О системе, Данные, Карта ↔ схема, Область применения), включая интерактивный переход «объекты на карте ↔ ортогональная схема топологии».

## Как открыть

- Локально: открыть `index.html` в браузере (сборка и сервер не нужны).
- Через GitHub Pages: Settings → Pages → Deploy from a branch → `main` / root.

## Управление

- Панель внизу слева, стрелки внизу справа и клавиши ← → — переход между слайдами; кнопка рядом со счётчиком открывает показ во весь экран.
- Слайд 04 «Область применения»: кнопка «Как это будет работать» в каждом блоке открывает мини-экран с демонстрацией (Esc или крестик — закрыть). В «Планировании застройки» объекты района включаются и отключаются, решение считает нужную модернизацию сети и источника.
- Слайд 03 «Карта ↔ схема»: три вида — «На карте», «На схеме», «Схема объекта». Клик по объекту — паспорт и его линии, двойной клик или кнопка — схема оборудования объекта, «Смоделировать отключение» — какие объекты останутся без питания.

## Файлы

- `index.html` — разметка слайдов
- `styles.css` — стили
- `app.js` — карта, навигация, логика слайда «Карта ↔ схема»

Сеть и карта на слайдах условные (демонстрационные данные).

Подложка карты на слайде «Карта ↔ схема» — `img/moscow-base.svg`, взята из репозитория 1Lux0r1/AISRKII (`design/assets/map-dark-plain.svg`); показан центр города и части соседних округов.

## Автономная версия

`offline.html` — вся презентация одним файлом (стили, скрипт, карта и шрифт Onest встроены). Открывается без интернета; пересобирается при каждом обновлении вместе с `index.html`.

## Сборка

`node build/assemble.js` пересоздаёт `index.html` и `offline.html` из слайдов в `build/canvas/project/`. Подробности и текущее состояние работы — в `HANDOFF.md`.
