# Схема электроснабжения — цифровой двойник Москвы

Рабочий макет презентации: шесть слайдов, включая интерактивный переход «объекты на карте ↔ ортогональная схема топологии».

## Как открыть

- Локально: открыть `index.html` в браузере (сборка и сервер не нужны).
- Через GitHub Pages: Settings → Pages → Deploy from a branch → `main` / root.

## Управление

- Верхняя панель и стрелки ← → на клавиатуре — переход между слайдами.
- Слайд 02 «Решения»: кнопка «Как это работает» в каждом блоке открывает мини-экран с демонстрацией (Esc или крестик — закрыть).
- Слайд 04: три вида — «На карте», «На схеме», «Схема объекта». Клик по объекту — паспорт и его линии, двойной клик или кнопка — схема оборудования объекта, «Смоделировать отключение» — какие объекты останутся без питания.

## Файлы

- `index.html` — разметка слайдов
- `styles.css` — стили
- `app.js` — карта, навигация, логика слайда «Карта ↔ схема»

Сеть и карта на слайдах условные (демонстрационные данные).
