## Как вносить правку

1. Изменить разметку слайда в `build/canvas/project/…dc.html` (или `build/scheme.html`, `build/demos.html`), стили — в `styles.css`, логику — в `app.js`.
2. Собрать: `node build/assemble.js` — пересоздаёт `index.html` и `offline.html`. Коммитить оба: `offline.html` легко забыть.
3. Проверить в браузере (Playwright, лучше `offline.html` с отключённой сетью): слайды листаются, консоль без ошибок.
4. Закоммитить и запушить в `main`. Ветка `gh-pages` по истории разошлась с `main` (force-push запрещён), поэтому публикация — коммитом с тем же деревом: `git fetch origin gh-pages && git push origin $(git commit-tree HEAD^{tree} -p FETCH_HEAD -m "Publish main"):refs/heads/gh-pages`.
5. Отправить заказчику свежий `offline.html`.

Особенности сборки: `PowerScheme.dc.html` на сайт не идёт — вместо него берётся `build/scheme.html`; при правке слайда 3 менять оба файла. `PowerNav.dc.html` тоже только для холста: навигация сайта — `navHTML` в `app.js`. Сетевая модель слайда 3 продублирована в `app.js` и в `PowerScheme.dc.html`.

1. **О системе** (`#about`) — заголовок, пять преимуществ, итог «Единственная в России… в контуре Правительства Москвы».
2. **Данные** (`#data`) — пять источников → единая модель → цифры; наведение на источник подсвечивает его долю его цветом.
3. **Карта ↔ схема** (`#scheme`) — три вида: карта, ортогональная схема, схема объекта; отключение объекта.
4. **Область применения** (`#tasks`) — слева три блока «План на 2027 год», справа рабочая область: первая демонстрация открыта сразу, клик по блоку переключает её, Esc возвращает заглушку. Плашка «План на 2027» одна — справа от заголовка.
5. **Эффект** (`#effect`).
