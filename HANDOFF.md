## Как вносить правку

1. Изменить разметку слайда в `build/canvas/project/…dc.html` (или `build/scheme.html`, `build/demos.html`), стили — в `styles.css`, логику — в `app.js`.
2. Собрать: `node build/assemble.js` — пересоздаёт `index.html` и `offline.html`. Коммитить оба: `offline.html` легко забыть.
3. Проверить в браузере (Playwright, лучше `offline.html` с отключённой сетью): слайды листаются, консоль без ошибок.
4. Закоммитить и запушить в `main`. Ветка `gh-pages` по истории разошлась с `main` (force-push запрещён), поэтому публикация — коммитом с тем же деревом: `git fetch origin gh-pages && git push origin $(git commit-tree HEAD^{tree} -p FETCH_HEAD -m "Publish main"):refs/heads/gh-pages`.
5. Отправить заказчику свежий `offline.html`.

Особенности сборки: `PowerScheme.dc.html` на сайт не идёт — вместо него берётся `build/scheme.html`; при правке слайда 3 менять оба файла. `PowerNav.dc.html` тоже только для холста: навигация сайта — `navHTML` в `app.js`. Сетевая модель слайда 3 продублирована в `app.js` и в `PowerScheme.dc.html`.

Содержимое каждого слайда лежит в `.deck-body` и целиком уменьшено до 90,5 %, чтобы уместиться под шапкой, — внутри слайдов вёрстка по-прежнему в координатах 1920×1080. Вкладки разделов 01–04 и 06 никуда не ведут: этих разделов в репозитории нет. Логотип ЦГУ — заглушка.

## Слайды сейчас (4)

1. **О системе** (`#about`) — сверху плашка «Первая в России единая цифровая модель электроэнергетики мегаполиса», слева анимированная сцена (организации → единая модель → карта города; стили `.ab-*`, карта `img/moscow-clear.svg`, плашки организаций ведут на слайд 2 с выбранным источником), справа три лозунга (`.ab-slogan`). Тексты лозунгов — заказчика.
2. **Данные** (`#data`) — пять источников → единая модель → цифры; наведение на источник подсвечивает его долю его цветом.
3. **Карта ↔ схема** (`#scheme`) — три вида: карта, ортогональная схема, схема объекта; отключение объекта. Схема объекта строится функцией `objDetail` из тех же данных, что значок объекта на ортогональной схеме (шины `buses`, генераторы `gens`, присоединения — линии сети); при отключении линии на карте и схеме мерцают и гаснут, на схеме объекта гаснут шины и оборудование. Выделение снимается повторным кликом, кликом по свободному месту или Esc.
4. **Область применения** (`#tasks`) — слева три блока «План на 2027 год», справа рабочая область: первая демонстрация открыта сразу, клик по блоку переключает её, Esc возвращает заглушку.
